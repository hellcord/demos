Гит хранит снимки

Демо к шортсу HellCord. Это симуляция: каждый коммит кладёт изменённый файл в хранилище целиком — дифф гит не записывает, он вычисляет его на лету. Нажми git gc — и похожие файлы упакуются в дельты.
